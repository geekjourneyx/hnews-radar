### 综合强信号

#### S-001｜Trail of Bits：Agent 先造确定性审计工具，再审代码

Trail of Bits 的文章发表于 2026-09-18，今天在 HN resurfacing，不作为“今日新发布”处理。团队公开了 MASM LSP、反编译器、静态分析相关工具与 Lean 模型，并说明这些工具被用于 Miden VM 安全审计。

真正的强信号是 workflow：模型把领域理解沉淀成 parser、IR、analysis pass 与 proof model，后续人工与 Agent 都可以复用同一套 deterministic substrate。模型更便宜后，最值得投入 token 的工作可能不是多跑一轮 review，而是建设让未来每一轮 review 都更便宜、更确定的工具。

#### S-002｜ServingStudio：高速 simulator 可能是 Infra Agent 的关键 Harness 资产

UW SyFI Lab 公开 ServingStudio：Simulator 根据实测 GPU kernel timing 模拟 serving，Agent 在模拟环境中寻找候选优化、修改真实 framework，再回到硬件验证。

项目方报告 simulator 最高可达 real-time 的 2,770×，并给出多个吞吐提升案例；这些总体数字当前标为 author_claim。SGLang PR #38560 提供了具体 patch、硬件/模型/请求配置、重复 run、profile mechanism 与 reproduction inputs，是较强的可审计佐证；PR 当前仍为 Draft，不能写成已 upstream merge。

反直觉点是：Infra Agent 的 leverage 可能主要来自一个足够快、足够可校准的“数字实验室”，而不是模型单次 reasoning 更聪明。

#### D-003｜“Good enough AI”在高保证工程里真正意味着什么

#### O-001｜Agent identity gateway 正从安全建议变成独立基础设施类别
